# 🛍️ Shoppy Globe

Shoppy Globe is a responsive e-commerce web application built using React.js. It allows users to browse products, search for products, view product details, add products to a shopping cart, and complete a dummy checkout process.

# Features
   - Home Page with Hero Section
   - Product Listing
   - Product Search by Product name or brand name
   - Product Details Page
   - Add Products to Cart
   - Increase or Decrease product quantity
   - Remove Products from Cart
   - Cart total calculation
   - Checkout Page
   - Responsive design for mobile and desktop
   - 404 page for invalid routes
   - Dynamic routing using React Router
   - Cart State management using Redux Toolkit

# Technologies Used
    - React.js
    - Vite
    - Javascript
    - React Router DOM
    - Redux Toolkit
    - React Redux
    - CSS
    - DummyJSON API

# Run the Project
    npm run dev

# How to Use
    1. Open the Shoppy Globe home page.
    2. Click Shop Now to click products.
    3. Browse or Search for products.
    4. Click on product to View its details.
    5. Add products to Cart.
    6. Open the cart and modify quantities if required.
    7. Proceed to checkout.
    8. Enter the required user details.
    9. Click place order.
    10.The Order confirmation message is displayed and the cart is cleared.

# API
    - Product Data is fetched from the DummyJSON products API as 
    "https://dummyjson.com/products"
    - The Application uses API data to display product information such as 
        - Product title
        - Product Image
        - Price
        - Rating
        - Category
        - Description
        - Stock Management

# State Management
    - Redux Toolkit is used to manage the shopping cart state.
    - The cart suppourts
        - Adding Products
        - Removing Products
        - Updating Quantites
        - Calculating total items
        - Calculating total price
        - Clearing the cart after placing an order
